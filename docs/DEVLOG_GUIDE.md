# Devlog

One file per phase: `phase-00.md` through `phase-10.md`.

Claude Code opens the file **before** starting the phase and appends to it
while working. It is raw working notes — messy is fine, truthful is required.

Record:

- what was tried
- what broke, and the **actual observed symptom** (not the diagnosis)
- what was changed, and why
- anything surprising
- anything deferred to a later phase

This is where the "What we tried that didn't work" section of
`Explanation.html` comes from. If it isn't in here, it doesn't go on the page.

Suggested shape:

```
# Phase 04 — Traffic and hazards

## Attempt 1 — global traffic pool
Tried: …
Observed: …
Why it failed: …

## Attempt 2 — …

## Surprises

## Deferred
```
