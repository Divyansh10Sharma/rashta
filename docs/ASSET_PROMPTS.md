# Game pictures — copy, paste, save

## How to do each one

1. Copy the prompt into your image generator.
2. Remove the black background (any background remover, e.g. remove.bg).
   **Skip this step** for anything marked _keep background_.
3. Convert to WebP at [squoosh.app](https://squoosh.app) (free). If it asks
   about size, make the longest side 512.
4. Save it with the exact name and folder shown.

Look at every picture before saving. **If it has any words, letters or logos
on it, make it again.**

**Tip:** make number 1 first. If your generator lets you attach a picture,
attach number 1 to every prompt after it, so everything matches.

## Road textures — download these, don't generate

Generated road pictures show seams when they repeat. These are free and repeat
perfectly.

### 38. Road

1. Go to [ambientcg.com](https://ambientcg.com) and search **Asphalt**.
2. Pick one you like and download **1K-JPG**.
3. Inside the zip, take the file ending in `_Color.jpg`, convert to WebP, and
   save as `public/textures/asphalt.webp`.
4. Take the file ending in `_NormalGL.jpg`, convert, and save as
   `public/textures/asphalt-normal.webp`.

### 39. Concrete

Same steps, search **Concrete**, save as `public/textures/concrete.webp` and
`public/textures/concrete-normal.webp`.

### 40. Brick

Same steps, search **Bricks**, save as `public/textures/brick.webp` and
`public/textures/brick-normal.webp`.
